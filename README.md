# Chifbay · private boat trips in Funchal, Madeira

Chifbay runs private boat trips from Marina do Funchal, Madeira: the whole boat for up to 5 guests, two licensed local skippers, a day trip with a swim at Fajã dos Padres or a sunset cruise to Cabo Girão, from €400 per boat. This repository holds the source of the website.

**Visit [chifbay.com](https://chifbay.com)** · **[Book a private boat trip](https://chifbay.com/book.html)**
